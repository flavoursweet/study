# 星迹 · 自律图鉴

独立的个人自律工具，亮咖色新粗野主义界面。原生 HTML / CSS / JavaScript，无运行依赖。

## 运行与部署

```sh
cd /workspace/study
node scripts/build.cjs
python3 -m http.server 8001 --bind 127.0.0.1 --directory dist
```

EdgeOne Pages：分支 `main`，框架 Other，根目录 `./`，安装命令 `echo No dependencies to install`，构建命令 `node scripts/build.cjs`，输出目录 `dist`。配置已写入 edgeone.json。首页直接显示自律工具。

## 功能

- 今日行动：查看所选日期的计划、打卡、保存晚间复盘。
- 规划下一天：保存到所选日期的次日，每日最多 3 个任务；填写内容与完成标准。
- 学习成果：按日期倒序展示截至今天的全部规划和复盘总结，已完成、未完成任务均显示，包括旧版有类别的任务。每一天的规划与复盘对应展示，没有复盘或规划时明确提示。
- 支持全部历史、最近 7 天、最近 30 天筛选，以及日期／规划／复盘内容搜索；每次加载 20 天，可继续加载历史。
- 可从历史记录跳转到当日补充复盘；只反映当前保存的记录，不保存已删除任务的版本历史。
- 去掉成果统计图表和阶段总结编辑器。旧周目标与已保存阶段总结保留在折叠存档，继续包含在个人备份里。
- 精灵图鉴：当天至少一个任务且全部完成时领取一次奖励；领奖后当天任务锁定。四张候选卡依次解锁，收齐后奖励成长星，不清空累计收藏。

## 精灵配置

app.js 中的 SPIRITS 数组可修改。火花、水蓝蓝、喵喵、迪莫为候选；世界收录与热度未核实，R / SR / SSR 为暂定分级，卡面为原创属性符号占位。修改时保留原 id 以保留已有收藏映射。

## 数据

数据保存在当前浏览器 localStorage，按来源隔离，无账号或云同步。顶部导出备份；底部“数据备份与恢复”导入。换域名需手动备份迁移。旧任务、周目标、复盘、收藏与阶段总结继续兼容，社交功能已移除。

历史按任务计划日期归档，日期使用设备本地时间。未来计划在“今日行动”选择对应日期查看，历史页截至今天。
