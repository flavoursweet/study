# 星迹 · 自律图鉴

移动端优先的个人自律工具，采用亮咖色新粗野主义界面。原生 HTML/CSS/JavaScript，无构建与运行依赖。这是独立仓库，不依赖旅行项目。

## 运行

```sh
cd /workspace/study
python3 -m http.server 8001 --bind 127.0.0.1
```

浏览器访问该服务即可使用。建议通过固定 HTTP 来源使用，避免切换端口或直接 file 打开造成浏览器本地存储隔离。

## 已实现

- 学习成果页取代周规划：完成任务数、有成果天数、复盘数、完成率、近 14 天趋势、按日期归档的成果时间线。
- 支持全部时间／近 7 天／近 30 天筛选、任务与复盘搜索、历史记录跳转；时间线每次加载 20 天。
- 阶段总结可由真实任务及复盘整理草稿，手动编辑保存，并随个人备份导出／恢复；切换范围提示保护未保存内容。
- 旧周目标保留在折叠存档中，不再创建新的周目标。
- 规划所选日期的下一天任务，每天最多 3 个；显示目标日期，填写任务内容和完成标准。类别、预计分钟、周目标关联已从新任务表单移除，旧记录继续兼容。
- 完成打卡、晚间复盘；通过顶部日期查看计划，复盘区不再显示下一天跳转按钮。
- 当天所有任务完成后每日领取一次卡片，领取后任务锁定。不可补领或提前领奖。复盘可继续编辑。
- 四张候选精灵卡依次解锁，无重复抽卡；收齐后获得成长星。收藏中断不清零。
- 翻卡动画与减少动态效果支持。
- 个人完整备份与恢复、损坏数据保护、导入格式和大小检查。

## 卡片配置

修改 app.js 开头的 SPIRITS 数组。当前候选为火花、水蓝蓝、喵喵、迪莫；《洛克王国世界》收录情况和人气排序尚未核实。R / SR / SSR 是演示分级，不是官方评级或有数据依据的热度排行。图形是属性符号占位，不是实际精灵立绘。后续替换名称、分级及已确认的图片素材时，请保留已有 id，以保留收藏映射。

## 个人数据

数据保存在当前浏览器 localStorage，按设备与网站来源隔离。使用顶部“备份数据”导出完整备份，页面底部“数据备份与恢复”导入。清理浏览器数据会丢失记录，日期使用设备本地时间。

本版本移除了昵称、小队、好友和进度分享。旧版本个人任务、周目标、复盘及收藏继续读取；导入旧备份时仅保留个人记录，不保留原有社交信息。没有账号或云同步。

## 独立部署到 EdgeOne Pages

创建独立 Pages 项目并连接本仓库：

| 配置项 | 值 |
| --- | --- |
| 生产分支 | main |
| 框架 | Other |
| 根目录 | ./ |
| 安装命令 | echo No dependencies to install |
| 构建命令 | node scripts/build.cjs |
| 输出目录 | dist |

`edgeone.json` 保存了同样的构建设置。发布目录只包含网页文件；首页直接显示自律工具，无需 `/self-discipline/` 路径。

部署后在新项目中添加自定义域名 `study.wangyujian.top`，按 EdgeOne 给出的目标添加主机记录为 `study` 的 CNAME，以及平台要求的验证记录。等待验证和 HTTPS 证书就绪。不修改主域名和旅行项目的 DNS 记录。先确认临时域名页面正常，再绑定正式域名。

### 原地址数据迁移

原站点顶部“备份数据”导出个人 JSON，然后在新域名的页面底部“数据备份与恢复”中导入。localStorage 按网站来源隔离，换域名不会自动迁移数据。

## 学习成果统计口径

统计截至设备本地今天，按任务计划日期归档。未来任务不计入；旧任务明确标为运动或生活的记录不计入学习任务统计，其他未分类任务计入。完成率为选定范围内完成任务数除以总任务数，无任务时显示“—”。有成果天数为存在已完成学习任务的日期数；每日复盘有内容即计为一篇。历史记录仍可查看和编辑，未完成任务不作为成果展示。

趋势展示所选范围内最近最多 14 天。搜索只过滤时间线，不改变范围统计及总结素材。阶段总结是基于已有记录的文字草稿，不使用 AI 推断能力；每个范围保留一份总结（同一范围再次保存会更新），最近 7／30 天按实际起止日期分别存档。旧周目标、个人任务、复盘和收藏继续兼容。
